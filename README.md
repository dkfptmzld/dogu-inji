# 도구인지 활동 (이루리 실버 스포츠)

어르신 도구인지 수업용 오프라인 튜토리얼. USB에 담아 인터넷 없이 브라우저로 여는 HTML 한 장 + 영상 폴더.

- 결과물: `deliverable/도구인지활동.html` + `deliverable/videos/`
- 휴대폰용 한 파일: `python pipeline/build_mobile.py` → `휴대폰용/도구인지활동_휴대폰용.html` (저장소에는 넣지 않음)
- 3D 영상: `pipeline/cube_3d` (three.js + Playwright 렌더, `npm i` 후 사용)
- 작업 방법·결정 이력·남은 일: [`CLAUDE.md`](CLAUDE.md)
